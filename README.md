# TWS.kz application by Olzhas

Написано на Svelte (SvelteKit) при поддержке Vite.js, работает на Node.js.

## Редактирование контента

Весь редактируемый фронт-энд контент расписан в тэге \script\ в файле */src/routes/+page.svelte*

После редактирования данного файла изменения необходимо зафиксировать. Для этого:

1. Нажмите на Node.js под доменом tws.kz
2. Далее нажмите "Запустить скрипт"
3. Введите **build** и запустите
