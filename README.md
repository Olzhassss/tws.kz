# TWS.kz application by Olzhas

Написано на Svelte (SvelteKit), работает на Node.js.

## Редактирование контента

Весь редактируемый фронт-энд контент расписан в тэге \script\ в файле /src/routes/+page.svelte

После редактирования данного файла изменения необходимо зафиксировать с помощью следующией команды:

```bash

npm run build

```
